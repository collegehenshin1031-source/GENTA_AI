# 🦅 源太AI ハゲタカSCOPE

中型株（時価総額300億〜2000億円）の出来高急動を自動検知するツールです。

## 🎯 機能

### 📊 出来高急動モニター
- 252営業日（1年）の平均出来高と比較
- **3倍以上**: 🔴 異常な資金流入
- **1.5倍以上**: 🟠 注目すべき動き

### 🔍 ハゲタカ監視
- 特定銘柄のM&A可能性を分析
- 独自スコアリングで予兆を検知

### 🔔 メール通知
- 利用者が自分のGmailを設定
- 出来高急動を検知するとメール通知

## 🚀 デプロイ方法

### Streamlit Cloud

1. このリポジトリをFork
2. [share.streamlit.io](https://share.streamlit.io/) にアクセス
3. 「New app」でリポジトリを選択
4. `app.py` を指定してデプロイ

## 📧 メール通知の設定方法

利用者が各自で設定します（運営側の設定不要）

1. アプリの「🔔 通知設定」タブを開く
2. Gmailアドレスを入力
3. Gmailアプリパスワード（16桁）を入力
4. 「保存」→「テスト送信」で確認

### アプリパスワードの取得方法

1. [myaccount.google.com](https://myaccount.google.com/) にアクセス
2. セキュリティ → 2段階認証を有効化
3. [アプリパスワード](https://myaccount.google.com/apppasswords) で生成
4. 16桁のパスワードをコピー
